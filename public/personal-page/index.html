Quantum Computing

Quantum Simulation · PyPI + Cross-Platform App

novum-qvm + QuantumLab

novum-qvm is a pure-Python quantum circuit simulator built on the four-layer Perlin-Fourier Quantum Virtual Simulation (PFQVS) framework, with NumPy as its only dependency. QuantumLab runs the same engine in a Flutter app for web, Android, and iOS, with a visual circuit builder, a 3D Bloch sphere, and 15 guided lessons through OpenQASM. pip install novum-qvm

Research Paper · Target: arXiv

PFQVS: Perlin-Fourier Quantum Virtual Simulation

The paper behind novum-qvm. It documents Perlin-noise state initialization, O(N) Fourier-domain gate execution, octave-weighted decoherence modeling, and importance-sampled measurement, with benchmarks against IBM's quantum hardware queue and a section on limitations.

Arabic Language

Arabic Linguistics · Bilingual Site · Live

انهف: Arabic Neopronoun System

Bilingual Arabic and English reference for انهف, a new gender-neutral Arabic pronoun for speakers who don't identify with the existing feminine, masculine, or plural categories. Includes full conjugation rules across attached object markers, prepositions, possessives, and verb prefixes.

Arabic NLP · Computational Humanities

Quranic Stylometric NLP Pipeline

Machine learning pipeline applying stylometric analysis to Quranic Arabic: authorship attribution, rhetorical structure detection, and intertextual cross-referencing. Planned next: a retrieval pipeline with an evaluation harness over Quranic and classical Arabic text, and a model fine-tuned on classical Arabic poetry and Akkadian fragments.
